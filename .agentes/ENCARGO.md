# Encargo — PAGINA EYS

Proyecto: **sitio web de EyS - Ejes y Suspensiones**, taller de Villa Gobernador
Galvez (Santa Fe). HTML/CSS/JS plano, 11 paginas, publicado en GitHub Pages.

## Reglas que no se negocian

1. **Sin frameworks, sin build, sin dependencias nuevas.** HTML/CSS/JS plano.
2. **Cero recursos externos.** Unica excepcion autorizada: la etiqueta de Google Ads
   (googletagmanager.com). Las tipografias se sirven locales, no volver a Google Fonts.
3. **No inventar datos**: ni plazos de entrega, ni precios, ni especificaciones.
4. Los datos de contacto estan unificados con la ficha de Google: **no se cambian**.
5. **No borrar archivos ni carpetas.** Nunca borrar google6f4817e7bc103d04.html.

## Como lo verifica Claude despues

Levanta el servidor local y mira el sitio en el navegador. Despues del push,
GitHub Pages tarda 1 a 3 minutos.
